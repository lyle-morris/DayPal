# DayPal 1.6.0 Development

This document initializes the DayPal 1.6.0 development branch and captures the planned release scope.

## Release Focus

DayPal 1.6.0 focuses on user settings, privacy controls, anonymous analytics, and donation support.

## Planned Scope

- Add Use 12-hour format setting
- Add Celsius temperature setting
- Add reverse colors option for predefined themes
- Add anonymous analytics
- Add analytics opt-out section in the configuration page
- Add Donation / Tip Jar section in the configuration page

## Out of Scope for 1.6.0

- Theme customization
- Saved custom themes
- Health app integrations

These items are planned for DayPal 1.7.0 discovery/development.

## Development Branch

All 1.6.0 work should land in this PR through the `daypal-1.6.0-dev` branch before merging into `main`.
