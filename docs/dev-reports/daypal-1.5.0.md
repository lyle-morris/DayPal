# DayPal 1.5.0 Development

This branch tracks work for the DayPal 1.5.0 release.

## Goals

- Improve contrast for weather and heart rate icons by moving from outlined to filled artwork.
- Update default battery styling from purple `#AA55FF` to green `#00FF00`.
- Update default heart rate styling from green `#00FF00` to red `#FF0000`.
- Validate the date text is bold font weight `700`.
- Update the vertical divider from white `#FFFFFF` to gray `#555555`.

## Status

PRD and technical planning complete.
