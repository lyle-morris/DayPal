# Image resources

Add final production PNG icons here before the final package build.

Required metric groups:

- Weather: sunny, partly cloudy, rainy, storm, snow, fog
- Heart Rate
- Battery: charging and non-charging states
- Calories
- Steps

Theme color strategy:

- Default theme uses individual metric color icons.
- Color themes use white icons.
- White theme uses black icons.
- Black theme uses white icons.

The current development foundation draws simple text placeholders for icons until PNG assets are added.
