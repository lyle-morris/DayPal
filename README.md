# DayMate

DayMate is a friendly, configurable watchface for Pebble Time 2.

Version 1.7.0 introduces a configurable metric tray, selectable themes, Open-Meteo weather, and a clean clock-only layout.

## v1.7.0 goals

- Four configurable metric slots
- Supported metrics: Weather, Heart Rate, Battery, Calories, Steps
- Duplicate metric selections allowed
- None option for each slot
- Collapsed metric slots
- Responsive clock-only layout when all metrics are hidden
- Eight selectable themes
- Pebble system time format
- Leading zero toggle
- Open-Meteo weather provider

## Current build status

This repository currently contains the v1.7.0 development foundation. Binary font and icon resources should be added locally before final packaging.

## Required local assets

Place Roboto files in resources/fonts/:

- Roboto-Black.ttf
- Roboto-Bold.ttf
- Roboto-Regular.ttf

Place production metric icons under resources/images/.
